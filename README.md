# 喜財快餐 Xi Cai Bento Shop

**網站預覽：[https://bento-shop.vercel.app/zh](https://bento-shop.vercel.app/zh)**

---

為位於**新北市樹林區柑園街1段60號-1**的「喜財快餐」打造的多國語言官方網站與實體 A4 宣傳單，解決柑園工業區本地與外籍員工（泰國、越南、緬甸、柬埔寨）的訂餐溝通痛點。

## 功能

- 五國語言動態切換（中文 / 泰文 / 越南文 / 緬甸文 / 高棉文）
- 10 款主食、4 款湯品、4 款小菜完整菜單
- A4 多語並列宣傳單（`public/flyer.html`），支援一鍵列印
- 響應式設計，手機與桌機均適用

## 技術架構

- **框架**：Next.js 15 (App Router) + TypeScript
- **i18n**：next-intl
- **部署**：Vercel — [bento-shop.vercel.app](https://bento-shop.vercel.app/zh)
